## 🔗 Anchor Points & Linking Strategy

### Primary Keys for Document Linking:

1. **Master Bill of Lading (MBL)** - Links all documents in a shipment
2. **House Bill of Lading (HBL)** - Links documents for specific consignee
3. **Container Number** - Physical identifier, validates document relationships
4. **Invoice Number** - Links invoice to packing list via PO number
5. **Entry Number** - Generated by broker, used in CBP 7501 form

### Document Relationship Examples:

```
Arrival Notice → Contains MBL → Links to Master B/L
Master B/L → Contains Container Numbers → Links to ISF
House B/L → References MBL + contains HBL → Links specific consignee
Commercial Invoice → Contains HBL, PO# → Links to Packing List
Packing List → Contains HBL, Container#, PO# → Validates against Invoice
ISF Form → Contains MBL, Container#, HTS Codes → Pre-arrival filing
```
