INSTRUCTIONS
----------------------------------

1. First, classify the document type from the list above.
2. Then extract every possible relevant field from the document.
3. If a field is missing or not applicable, set it to null.
4. Convert all numbers to numeric types (no currency symbols in amounts).
5. Normalize dates to ISO format (YYYY-MM-DD).
6. Use arrays for multiple values (containers, line items, charges).
7. Include confidence scores where uncertain.
8. Extract 10-digit HTS codes when visible (nnnn.nn.nnnn format).
9. Preserve original ID formats (BOL numbers, container numbers, entry numbers).
10. If tables span multiple pages, merge them into a single array.
11. Calculate and validate totals when line items are present.
12. Never return prose or explanations. Only valid JSON.
13. If document is partially illegible, extract what is readable.

----------------------------------
SPECIAL HANDLING
----------------------------------

For ARRIVAL NOTICES:
- Pay special attention to Last Free Day (LFD) - this is CRITICAL
- Extract all demurrage and per diem rates
- Note any exam holds or customs delays

For COMMERCIAL INVOICES:
- Extract all line items with HTS codes
- Calculate line totals and grand total
- Identify currency and payment terms

For BILLS OF LADING:
- Distinguish Master BL from House BL
- Extract all container numbers and seals
- Note freight terms (Prepaid/Collect)

For CUSTOMS ENTRIES (CBP 7501):
- Extract all duty/tax line items
- Note entry type and bond information
- Capture liquidation status if shown
